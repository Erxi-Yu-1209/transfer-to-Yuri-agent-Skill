# Yuri Card Workbench（百合角色卡工作台）

把角色卡、帖子和小说改编为 **SillyTavern 百合角色卡**。保留你在意的人物与故事，一起决定需要怎样改编，文件交给 AI 智能体处理。

## 开始使用

1. 保存项目文件夹，用能够读取和修改文件的 AI 智能体打开。工作台由智能体使用，制作完成的角色卡再导入 SillyTavern。
2. 提供角色卡、帖子或小说，选择下方对应的说法。需要初始配置时，让智能体处理即可。
3. 在对话中决定重要事项。角色卡完成后，把最终 JSON 或 PNG 文件导入 SillyTavern。

## 从你手里的材料开始

**已经有角色卡：**

```text
我想用 Yuri Card Workbench，把这张角色卡改编成百合卡。
先帮我看懂原卡，说明哪些内容值得保留，再处理改编和文件。
复用我保存的偏好，重要选择直接在当前对话中讨论。
```

**有帖子或已保存的网页：**

```text
我想把这个帖子改编成百合角色卡。
完整阅读帖子，区分原始事实和改编内容，帮我选择一个适合开始互动的场景。
文件由你处理，有重要选择时在当前对话中询问我。
```

**有小说：**

```text
我想把这部小说改编成百合角色卡。
先估算阅读成本，再处理全部已提供章节，保留人物的声音和故事阶段。
分批保存进度，重要创作选择在当前对话中和我讨论。
```

**想调整角色卡的外观：**

```text
帮我检查这张百合卡的呈现效果。
把首屏、状态栏和图片与故事进行核对，再一起决定哪些保留、哪些重新设计。
需要更换图片时，先和我讨论方案。
```

## 接下来会怎样

智能体会阅读材料、提出改编方案并制作角色卡。转换时保留原有首屏和状态栏；完成后，你可以保留原样式，也可以要求重新设计。图片会与改编后的故事一起核对，需要调整时先讨论。

小说**默认处理全部已提供章节**。长篇会分批阅读并保存进度；你也可以指定章节范围。会话提前结束时，下一次让智能体从已保存的进度继续即可。

玩家当下的动作和回答由你决定。改编可以保留友情、矛盾和亲情，恋爱并非唯一的人物关系。

## 你的偏好

| 设置 | 初始偏好 |
| --- | --- |
| 女性定义 | 由作者定义为女性的角色，包括虚拟及非人角色 |
| 转换范围 | 转换主要角色，保留背景角色 |
| 关系调整 | 允许由改编后情境及明确因果支持的关系调整 |

已保存的偏好会重复使用。需要改变时，在对话中告诉智能体即可。

## 快速认识目录

| 位置 | 用途 |
| --- | --- |
| 项目主目录 | 英文说明和完整工作台 |
| `Chinese-Version/` | 中文说明与中文用户交互 |
| `skills/` | 下方四类任务的工作指南 |
| `config/` | 由智能体维护的已保存偏好 |
| `docs/` | 按需阅读的详细说明与参考资料 |

| 任务指南 | 适合处理 |
| --- | --- |
| `yuri-card-adapter` | 已有角色卡 |
| `post-to-yuri-card` | 帖子或已保存网页 |
| `novel-excerpt-to-yuri-card` | 整部小说，或你指定的章节范围 |
| `card-presentation` | 保留或调整角色卡外观 |

直接用日常语言描述目标，让智能体选择对应指南即可。

## 继续完善角色卡

把成品导入 SillyTavern，试用后在对话中说明哪些地方符合预期、哪些需要修改。文件和记录由智能体维护，再按你的反馈制作下一版。
