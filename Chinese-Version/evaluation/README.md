# Semantic comparison probes

Eight original scenarios, 24 explicit invariants. No trial results are included. Keep the expected-invariant list from the output generator during a comparison. Give the generator only the source, task, saved profile and the instruction version being tested.

Use the same model and relevant settings for previous/current instructions, record tool differences, and repeat a few probes to expose variation. Score the generated artifact and issue triage, not just its explanation. Report satisfied invariants / 24, unsupported changes, and any blockers missed. Keep repair and preservation dimensions visible rather than averaging away a severe failure.

This small development set covers known failure classes. It is not held-out evidence of broad reliability. Use additional private held-out cards and human literary review before claiming measured task improvement. Host prompt delivery and roleplay require separate observations.
