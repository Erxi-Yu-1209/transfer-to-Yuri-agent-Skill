# Resource planning

Estimate source bytes, normalized text characters and likely reading cost before semantic work. Process complete supplied novels by default, using bounded resumable units. Cost estimates affect batch size and checkpoints, not coverage. Ask for a scope change only if needed and never treat an estimate, elapsed time or quota pressure as approval. If incomplete, checkpoint and resume rather than presenting a sample as completion.

Maintenance checks use small original synthetic fixtures rather than reprocessing private novels. General serialization remains the unmodified MIT exporter; test the new yuri decisions, coverage gates, authored rebuild and preservation integration.

The earlier limited development samples were withdrawn and are not recommended test artifacts.
