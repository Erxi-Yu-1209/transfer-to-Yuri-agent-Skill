# Distribution boundaries

See `LICENSE` for the project licensing boundary and `THIRD_PARTY_NOTICES.md` for actual upstream code reuse, immutable blob identity, comments and the preserved MIT notice. Original implementation is distinguished from the unmodified exporter and method-only references. The repository MIT grant covers only newly written extension code, instructions, tests and documentation; existing Workbench v1.2.0 original files keep their prior, undecided status.

Supplied posts, novel text and EPUB material are private trial sources. Public allowlists omit their frozen excerpts, derived cards and casework. The Drive delivery contains those separately under ignored private-casework for the user's own review; that does not establish permission to publish source material. Full novels and EPUB artwork are not included in public code. The user-selected Drive folder is the delivery destination; no public sharing change is performed.
